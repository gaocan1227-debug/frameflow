# 帧序开源本机版 · 使用指南

这份指南对应公开仓库的 `oss-local` 分支。它在自己的电脑上运行，本机地址是 `127.0.0.1`，不需要注册、登录或购买积分。

## 1. 准备与启动

准备 Node.js 20 或更新版本，以及能在终端直接运行的 `ffmpeg` 和 `ffprobe`。FFmpeg 需包含 H.264 编码器 `libx264`；要将中文字幕写进画面，还需要 `libass` 的 `subtitles` 滤镜。浏览器使用近期版本的 Chrome、Edge 或 Safari。

从 GitHub 下载 `oss-local` 分支源码，或在终端运行：

```bash
git clone --branch oss-local https://github.com/gaocan1227-debug/frameflow.git
cd frameflow
npm start
```

终端出现“帧序开源本机版：http://127.0.0.1:3000”后，在浏览器打开该地址。保持终端窗口运行；停止服务时在终端按 `Ctrl+C`。打开页面或关闭浏览器不会删除项目。若 3000 端口已被使用，可在 macOS／Linux 执行 `PORT=3217 npm start`，然后打开 `http://127.0.0.1:3217`。

源码没有第三方 npm 依赖，无需运行 `npm install`。Mac 本机已经验证启动和导出；Windows、Linux 尚未做实体机验收。

## 2. 创建项目和导入文字

1. 点击左侧“＋ 新建”，输入项目名称。
2. 在“故事设定”填写画幅、画风和故事梗概，点击“保存设定”。竖屏选 `9:16`，横屏选 `16:9`。
3. 若已有小说，在“导入小说章节”粘贴正文，点击“导入为剧集”。程序按“第一章”“第二章”或 `Chapter 1` 一类标题拆分。导入后逐集打开，检查拆分结果与剧本内容。
4. 若从空白开始，点击“＋ 新增一集”，在“剧本 / 原文”中写内容，点击“保存剧本”。

章节导入是按标题分段保存原文，不会自动将小说改写成可拍剧本。导入与手动新增的剧集都会保存在本机项目数据中。

## 3. 建立人物、场景和分镜

在“人物资料”和“场景资料”点击添加，填写名称、描述及参考图提示词，然后分别保存。这些资料供全剧统一设定；填写提示词本身不会生成图片。

在当前剧集点击“＋ 添加镜头”。每个镜头填写画面与叙事动作、视频提示词、对白和时长。镜头依照显示顺序合成为成片；目前页面没有拖拽重排功能。剧本和镜头审阅完成后，可点击“确认剧本”“确认分镜”记录确认状态；这两个按钮只是状态标记，不会启动媒体生成。

## 4. 上传与绑定素材

在页面底部“素材库”选择本机文件上传。可用格式为 PNG、JPEG、WebP、MP4、MP3 和 WAV，单文件不超过 40 MB。上传后回到镜头的“画面素材”下拉框，选择对应图片或视频，并点击“保存镜头”。**每个待导出镜头都必须绑定图片或视频。**

- 图片：按镜头时长静止显示，不会让图片里的人物自动运动。
- 视频：在“素材入点（秒）”填写从原视频开始截取的位置；若未绑定逐镜配音，保留视频原声。
- 逐镜配音：先上传 MP3 或 WAV，再在镜头的“逐镜配音”选择它；选择后该镜使用配音替代原片声音。配音比镜头短时会循环到镜头结束，因此请在导出前检查时长。

每镜时长须为 1–30 秒。视频素材和音频素材由使用者自行提供；界面中的视频提示词不会自动调用生视频服务。

## 5. 字幕与配乐

镜头中的“对白”会按该镜头的时间自动写入字幕。需要额外文字时，在“字幕轨”填写起点、终点（单位秒）和文字，点击“＋ 添加字幕”。时间以整集开头为 0 秒，请确保结束时间大于开始时间，并落在成片范围内。

若要加背景音乐，先上传 MP3 或 WAV，在“背景音乐”选择文件并点击“保存配乐”。导出时背景音乐会循环、降低音量，并在末尾淡出。当前页面没有配乐音量调节，也不能编辑或删除已添加的字幕；如需修改，请在创建前核对文字与时间。

## 6. 导出与保存

确认每镜都有画面素材后，点击“导出 MP4”。导出完成后，页面显示预览播放器和“下载 MP4”链接。输出为 720×1280（9:16）或 1280×720（16:9）的 H.264／AAC MP4。导出程序会检查视频轨、音频轨以及与镜头总时长是否相符。首次导出或镜头较多时需要等待，期间不要关闭运行服务的终端。

默认文件位置：

| 内容 | 路径 |
| --- | --- |
| 项目、剧集、镜头、字幕等 | `data/projects.json` |
| 上传的素材 | `data/assets/` |
| 导出的 MP4 | `data/exports/` |

这三个路径相对于启动时所在的仓库目录。建议定期备份整个 `data/` 目录。若需要自定位置，可设置 `FRAMEFLOW_DATA_DIR` 环境变量。项目数据和素材不会自动上传到 GitHub；`data/` 已被 Git 忽略。删除源码目录前请先备份数据。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 页面打不开 | 检查终端是否仍显示服务正在运行，以及浏览器地址是否与终端端口一致。 |
| 提示找不到 `ffmpeg` 或 `ffprobe` | 确认命令已安装并位于终端的 `PATH`；也可通过 `FFMPEG_BIN`、`FFPROBE_BIN` 指定可执行文件。 |
| 导出提示缺少素材 | 逐镜选择图片或视频并点击“保存镜头”。音频文件不能替代画面素材。 |
| 中文字幕导出失败 | 检查 FFmpeg 是否包含 `subtitles` 滤镜和 `libass`。 |
| 上传失败 | 检查文件格式和 40 MB 单文件限制；当前上传一次选择一个文件。 |
| 换电脑后看不到项目 | 复制旧电脑的整个 `data/` 目录到新电脑对应位置，再启动。 |

## 功能边界

本开源分支以 GPT 本机版的本地制作流程为目标重新实现，但不是其原始源码。当前没有自动小说改编、AI 生图、生视频、TTS、供应商任务恢复、拖拽时间线或精细剪辑。任何外部素材和服务的使用权及费用需由使用者自行处理。
